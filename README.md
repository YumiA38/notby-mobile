# Notby

Notby is a mobile job-discovery prototype for entry-level and junior candidates. It combines job search, saved opportunities, a simple profile-strength indicator, and an application action in one focused mobile experience.

## Included MVP features

- Search jobs by title, skills, location, or company
- Filter by remote work, QA, and entry-level roles
- Save and remove jobs from a personal shortlist
- Review a job-detail sheet and start a quick application
- View simple job-search activity and profile strength

## Tech stack

- React Native
- Expo
- TypeScript

## Run locally

```bash
npm install
npx expo start
```

Use the Expo Go app on a phone or choose an Android/iOS emulator from the Expo terminal.

## Portfolio note

This is a front-end prototype with sample job data. Authentication, a real job API, notifications, CV upload, and backend application tracking are future extensions.
